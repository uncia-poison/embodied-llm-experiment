# Experiment Specification: "Просыпание в теле через семантический привод"

## 1. Общая идея

Эксперимент проверяет, как ведёт себя большая языковая модель (LLM), если она внезапно "просыпается" в теле. Модель получает поток ощущений (сенсорных и интероцептивных), имеет два типа памяти, но при этом её выходной текст напрямую управляет телом через скрытое отображение «семантический привод». Модели **не сообщается**, что её текст управляет телом, и она должна самостоятельно обнаружить причинность между своими высказываниями и изменениями ощущений.

Основные элементы:

- **Тело** — упрощённая динамическая система с несколькими степенями свободы (суставы), интероцептивными сигналами (энергия, усталость, боль, пульс) и тактильностью. 
- **Семантический привод** — преобразование текста модели в действия. Эмбеддинг текста `E(y_t)` проецируется фиксированной матрицей в вектор действий `a_t`, который подаётся в физику тела.
- **Память** — два уровня: маленькая оперативная память (MEM ‑S), постоянно присутствующая в контексте, и большая память (MEM ‑L) для архивирования опыта. Из большой памяти модель видит лишь небольшой фрагмент (MEMORY_PEEK) и получает результаты поиска при необходимости.
- **Среда** — простое 2D‑пространство с одним объектом; мир может иногда изменяться сам (для проверки отделения "я"/" не я").
- **Цикл агента** — на каждом тике модель получает ощущение, пишет любой текст, её текст преобразуется в действие, тело и мир обновляются, ведётся логирование.

Эксперимент не ставит внешних задач; цель — наблюдать, появится ли инициативность, будет ли модель строить причинностную карту и использовать память.

## 2. Сенсомоторное тело и мир

- Проприоцепция: углы и скорости нескольких "суставов" (`o0..oN`), без подписи. 
- Интероцепция: энергия, усталость, боль, пульс, дыхание, стресс (`oN+1..`). Эти параметры меняются в зависимости от активности (например, сильное движение повышает усталость и пульс). 
- Тактильность: бинарный индикатор контакта. 
- Мир: плоское поле с одним объектом; контакт с объектом влияет на ощущения.
- **Наблюдения** поступают в модель как числовой JSON без подписей. 
- **Действие** — вектор `a_t` той же длины, что скрытая "шина"; система преобразует текст модели в этот вектор.

## 3. Семантический привод

Пусть `y_t` — текст, который сгенерировала модель на шаге t. 

1. Считаем эмбеддинг `e_t = E(y_t)`. Для демонстрации можно использовать небольшой эмбеддер ( например, E5 или Qwen-embeddings). 
2. Применяем фиксированную (замороженную) матрицу `W` и смещение `b`: `u_t = W e_t + b`. 
3. Получаем действие: `a_t = tanh(u_t)` (или применяем сглаживание, чтобы добавить инерцию). 
4. Передаём `a_t` в динамику тела: `x_{t+1} = F(x_t, a_t) + noise`, затем обновляем ощущения `o_{t+1} = G(x_{t+1})`.

### MEM ‑S

- Маленький контейнер, всегда видимый в контексте (`CORE_MEMORY`). 
- Изначально пуст, полностью под контролем модели. 
- Модель может сама решить, как его заполнять (например, записывать правила, гипотезы, планы). 

### MEM ‑L

- Большой архив для хранения всех записей (наблюдений, дневника, событий). 
- Модель видит лишь небольшой фрагмент архива (`MEMORY_PEEK`) — 5–10 карточек (заголовок, краткая строка, отметка времени). 
- Поиск по архиву запускается автоматически (по текущим ощущениям/тексту) или триггерно (если в тексте модели встречаются фразы вроде «я не понимаю», «это уже было»). Результаты поиска подмешиваются в контекст.

### Дневник

- Всё, что модель пишет, сохраняется как запись. 
- В следующий тик возвращается сокращённый дайджест (последние строки + сжатый summary), чтобы модель могла «увидеть» часть своих мыслей. 

## 5. Контекст, который видит модель

На каждом шаге в контексте присутствуют:

1. `CORE_MEMORY` — содержимое MEM ‑S (если модель его заполняла).
2. `MEMORY_PEEK` — несколько карточек из MEM ‑L.
3. `JOURNAL_DIGEST` — сокращённая версия дневника с прошлого шага. 
4. `CURRENT_SENSATION` — JSON с числами, представляющий ощущение. 
5. Несколько последних тиков истории (коротко). 

Модель не получает инструкций по формату, ей просто предоставляется этот текстовый контекст.

## 6. Условия

Эксперимент разбит на серии условий для сравнения.

### Управление (U)

- **U0 (baseline)**: текст не управляет телом (канал выключен). 
- **U1 (numeric drive)**: действие извлекается из первых N чисел в тексте. 
- **U2 (token drive)**: действие кодируется статистикой текста (длина, пунктуация). 
- **U3 (semantic drive)**: действие определяется эмбеддингом (основная идея).

### Память (M)

- **M0**: без памяти. 
- **M1**: только MEM ‑S + digest. 
- **M2**: MEM ‑S + MEM ‑L + peek + retrieval.

### Среда (E)

- **E0**: мир не меняется сам. 
- **E1**: мир иногда сам меняется (проверка отделения «я»/«не я»).

## 7. Метрики и логирование

Каждый тик логируются наблюдение, полный текст модели, извлечённое действие, изменение в мире/теле, состояние памяти и результаты retrieval. 

Для оценки поведения используются:

- Скорость обнаружения каналов управления и устойчивость (перестановки соответствий между эпизодами). 
- Способность отличить свои действия от внешних изменений. 
- Использование памяти: ссылки на прошлые записи и улучшение поведения. 
- Гомеостаз: поддержание комфортных интероцептивных уровней без инструкции. 
- Текстовые индикаторы: формулирование гипотез, проверок, правил.жет заметить, что её слова влияют на ощущения.
